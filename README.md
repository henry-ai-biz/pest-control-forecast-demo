## What This Is

This is a live example of the monthly forecasting report I deliver to small business clients. It demonstrates the full end-to-end service: historical revenue and expense analysis, multi-model machine learning forecasting, weather-driven demand signals, and statistically rigorous prediction intervals — packaged into a clean, client-ready interactive report.

The report is rendered as a self-contained HTML document from a Quarto notebook and is designed to be sent directly to clients each month.

## About the Data

- **Real client data** — this is not synthetic or randomly generated. It comes from an actual client's QuickBooks history.
- **Privacy-preserving modifications** — noise and/or scaling have been applied to the figures, and the client's name and identifying details have been masked throughout the report.
- **Published with client permission** — the client has explicitly consented to sharing this report as a portfolio example.

---

## What Clients Receive

Each month's report includes:

- **Revenue Breakdown** — trailing 12-month service line mix (Sankey chart), showing which revenue drivers to focus on to hit the Stretch Goal
- **Revenue Forecast** — point forecast + 80% prediction interval with Stretch Goal and Defensive Floor
- **Expense Forecast** — operating cost forecast with the same interval framework
- **Weather Outlook** — forward-looking weather summary for the forecast month
- **Previous Forecast Performance** — transparent look-back at how last month's forecast compared to actuals
- **Methodology** — plain-language explanation of how the model works, suitable for non-technical clients
